Pusat bantuan

Panduan penggunaan

Alur lengkap dari login sampai evidence berhasil diproses.

1. Masuk ke sistem

Gunakan identitas kerja yang sudah mendapat akses.

  1. Pilih masuk dengan Microsoft.
  2. Gunakan akun Entra yang sudah didaftarkan admin.
  3. Jika akses ditolak, minta admin memeriksa email dan status pengguna.

2. Hubungkan emica

API key pribadi diperlukan untuk pencarian dan unggah.

  1. Buka menu Kredensial.
  2. Pastikan email yang tampil sama dengan akun emica.
  3. Ikuti panduan pembuatan API key, lalu simpan.

3. Cari service booking

Cari memakai nomor booking atau diagnose.

  1. Buka menu Service.
  2. Masukkan minimal tiga karakter, misalnya SB/D0302/26/07284.
  3. Pilih hasil yang tepat dan periksa informasi kendaraan.

4. Unggah evidence

Pastikan file sesuai service yang dipilih.

  1. Pilih foto atau video pada halaman detail service.
  2. Gunakan JPEG, PNG, WebP, MP4, atau MOV; maksimal 25 MiB per file.
  3. Unggah maksimal empat file per permintaan dan tunggu proses selesai.

Masalah umum

Langkah awal sebelum menghubungi admin.

Kredensial diperlukan
Buka menu Kredensial dan simpan API key pribadi.
Pencarian gagal
Periksa nomor booking atau diagnose, lalu coba lagi.
File ditolak
Periksa format, isi, jumlah, dan ukuran file.
Akses ditolak
Hubungi admin dan sertakan Request ID dari bawah halaman. Jangan sertakan API key.
